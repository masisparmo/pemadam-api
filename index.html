Konsep Dasar Pemadaman Api Akustik

Bagaimana Suara Bisa Memadamkan Api Tanpa Air?

Bayangkan saat Anda meniup lilin ulang tahun. Lilin padam bukan karena ludah atau air, melainkan karena embusan udara Anda memisahkan uap panas lilin dari oksigen di sekitarnya. Vortex Tech karya Ángela Karime Venegas Hernández melakukan hal yang sama, tetapi menggunakan "peluru cincin udara tak kasatmata" yang ditembakkan oleh suara bass berfrekuensi sangat rendah (30 Hz) sebanyak 30 kali setiap detik!

1

Detak Bass 30 Hz

Pembangkit frekuensi mengirimkan nada bass sangat rendah (30 Hz) ke amplifier dan speaker. Nada ini membuat membran speaker bergetar maju-mundur dengan dorongan fisik yang kuat sebanyak 30 kali per detik.

2

Tabung Kolimator

Tanpa tabung, suara akan menyebar ke segala arah dan tenaganya hilang. Tabung silinder dengan lubang moncong sempit (kolimator) memfokuskan gelombang suara agar lurus ke satu titik sasaran.

3

Cincin Pusaran (Vortex)

Saat dorongan udara melewati lubang sempit di ujung tabung, tepian udara menggulung membentuk cincin pusaran berputar (vortex ring)—mirip cincin asap yang melesat lurus menembus udara.

4

Meruntuhkan Segitiga Api

Tembakan 30 cincin vortex per detik mengacak-acak dasar api, mengusir molekul oksigen dari uap bahan bakar, dan mendinginkan suhu nyala. Tanpa oksigen, api langsung mati lemas dalam hitungan detik!

🎯 Mengapa Harus Frekuensi Rendah (30–60 Hz)?

Banyak orang mengira suara melengking tinggi (seperti penyanyi opera yang memecahkan gelas) bisa mematikan api. Namun riset George Mason University dan Vortex Tech membuktikan sebaliknya:

❌ Frekuensi Tinggi (> 200 Hz hingga Ultrasonik 20.000 Hz)

Getarannya sangat cepat tetapi jarak gerak maju-mundur membran speaker sangat pendek (mikrometer). Udara hanya bergetar tipis di tempat sehingga nyala api hanya bergetar kecil namun tidak padam.

✅ Frekuensi Bass Rendah (30 Hz – 60 Hz)

Membran subwoofer bergerak maju-mundur sejauh beberapa milimeter hingga sentimeter, memompa volume udara yang besar pada setiap detaknya. Dorongan makro inilah yang sanggup menyapu bersih oksigen di pangkal api.

4 Hukum Fisika di Balik Pemadam Api Akustik

Prinsip pemadaman api dengan gelombang suara telah diteliti secara mendalam oleh DARPA (Instant Fire Suppression Program), Harvard University, George Mason University (Seth Robertson & Viet Tran), dan dioptimalkan menjadi perangkat portabel Vortex Tech oleh Ángela Karime Venegas Hernández. Berikut empat mekanisme fisika utamanya:

1. Akustika & Mekanika Gelombang λ = v / f

Gelombang Tekanan Longitudinal & Amplitudo Simpangan

Gelombang suara di udara adalah gelombang longitudinal yang terdiri dari fase rapatan (kompresi / tekanan tinggi) dan renggangan (rarefaksi / tekanan rendah). Untuk daya akustik yang sama, simpangan perpindahan partikel udara ($\xi$) berbanding terbalik dengan frekuensi:

ξ = v_partikel / (2π · f)  |  Pada f = 30 Hz, λ = 343 / 30 = 11,43 meter

Karena frekuensi $f = 30\text{ Hz}$ sangat rendah, simpangan gerak maju-mundur molekul udara menjadi jauh lebih besar dibandingkan frekuensi tinggi. Hal ini menghasilkan guncangan mekanis makroskopis pada zona pembakaran.

2. Dinamika Fluida (Vortex Ring) L / D ≈ 1.5 – 4.0

Synthetic Jet & Cincin Pusaran Toroidal (Vortex Rings)

Ketika pulsa tekanan 30 Hz dipaksa melewati bukaan sempit (orifice aperture) di ujung kolimator, lapisan batas udara di tepi lubang mengalami pemisahan aliran (flow separation) dan menggulung menjadi cincin pusaran toroidal (acoustic vortex ring).

Γ ∝ u₀² · Δt (Sirkulasi Vortex menjaga struktur cincin tetap fokus)

Berbeda dengan gelombang suara biasa yang melemah cepat secara sferis ($I \propto 1/r^2$), cincin vortex membawa momentum fluida terarah lurus ke depan (synthetic jet) sehingga mampu menghantam pangkal api dari jarak puluhan sentimeter hingga meter.

3. Termodinamika Pembakaran q̇_loss > q̇_gen

Penipisan Lapisan Batas Termal (Boundary Layer Thinning)

Berdasarkan laporan riset DARPA Instant Fire Suppression, osilasi kecepatan udara di sekitar nyala api menipiskan thermal boundary layer di atas permukaan bahan bakar.

δ_T ≈ (L / √Re) · Pr⁻¹/³  →  Kecepatan akustik naik ⇒ Re naik ⇒ δ_T menipis ⇒ Pendinginan cepat

Selain itu, getaran akustik menyebarkan nyala api ke area yang lebih luas, menurunkan kerapatan panas lokal di bawah suhu nyala minimum (ignition temperature).

4. Kinetika Kimia (Bilangan Damköhler) Da = τ_flow / τ_chem < 1

Regangan Nyala Kritis (Strain-Rate Extinction)

Api membutuhkan waktu tertentu ($\tau_{\text{chem}}$) agar molekul uap bahan bakar dan oksigen ($O_2$) bereaksi sempurna. Tembakan pulsa vortex menghasilkan laju regangan aliran ($\kappa$) yang sangat tinggi, sehingga memangkas waktu tinggal fluida ($\tau_{\text{flow}} \sim 1/\kappa$) menjadi jauh lebih singkat daripada waktu reaksi kimia ($\tau_{\text{chem}}$).

Da = τ_flow / τ_chem ≈ 1 / (κ · τ_chem) < Da_kritis ⇒ Reaksi Rantai Pembakaran Putus!

Oksigen dan uap bahan bakar dipisahkan lebih cepat daripada kecepatan reaksi kimia pembakaran itu sendiri, sehingga api langsung padam seketika (blow-off / suffocation).

Cara Membuat Prototipe Pemadam Api Gelombang Suara

Berdasarkan arsitektur 4 komponen utama Vortex Tech (Ángela Venegas) dan prototipe George Mason University.

⚠️ Catatan Keselamatan: Gunakan hanya untuk eksperimen sains skala kecil (seperti api lilin) di ruang terbuka dengan pendampingan dan APAR cadangan.

🔌 Skema Alur Rangkaian (Klik Komponen untuk Detail Perakitan):

1. Sumber Daya: Baterai 12V–24V DC

12V 7Ah SLA / 3S-6S Li-Ion

Dalam wawancara bersama N+, Ángela Venegas menjelaskan bahwa prototipe Vortex Tech menggunakan baterai 12 Volt agar alat dapat dibawa secara portabel (dimasukkan ke tas ransel/selempang). Untuk daya dorong ekstra pada amplifier Class-D seperti TPA3116D2, Anda bisa menggunakan baterai Lithium-Ion 3S (12.6V) hingga 5S/6S (18V–24V) dengan kapasitas arus minimal 5 Ampere, dilengkapi sakelar utama (Main Switch) dan sekring pengaman (Fuse 10A).

📌 Koneksi: Kutub (+) Baterai → Fuse 10A → Sakelar → Terminal VCC (+12V/24V) Amplifier & Step-Down 5V (untuk Generator Frekuensi).

📐 Kalkulator Ukuran Tabung Kolimator

Masukkan ukuran speaker subwoofer yang Anda miliki untuk menghitung dimensi tabung silinder dan diameter lubang moncong (orifice) yang optimal mencetak cincin vortex:

Diameter Dalam Tabung (D): 17.0 cm (Pipa PVC 6")
Panjang Tabung Ideal (L): 34.0 – 42.0 cm
Diameter Lubang Moncong (d): 7.5 cm (Rasio d/D ≈ 0.45)
Daya Amplifier Disarankan: 50W – 100W Mono

💡 Rahasia Desain: Jangan biarkan ujung depan pipa terbuka penuh! Pasang tutup pipa (end-cap) atau sekat akrilik/karton tebal di ujung depan, lalu lubangi bagian tengahnya dengan diameter ~40%–50% dari diameter tabung. Penyempitan inilah yang memicu pembentukan vortex ring.

🔧 5 Langkah Merakit Alat Secara Mandiri

  1. 1
    Siapkan Tabung Silinder (Kolimator): Gunakan pipa PVC, tabung karton tebal (cardboard tube), atau ember silinder sepanjang 30–45 cm yang diameternya pas dengan bingkai luar speaker subwoofer (misal 6 inci untuk subwoofer 6.5 inci).
  2. 2
    Pasang Subwoofer Kedap Udara di Ujung Belakang: Sekrupkan speaker menghadap ke dalam tabung. Pastikan celah antara pinggiran speaker dan dinding tabung rapat kedap udara (gunakan lem silikon atau foam tape) agar tekanan udara tidak bocor ke samping.
  3. 3
    Buat Moncong Pembentuk Vortex (Nozzle Aperture): Tutup ujung depan tabung dengan penutup datar berlubang lingkaran tepat di tengah (diameter sekitar 6–8 cm). Tepi lubang yang tegas akan menggulung hembusan bass menjadi cincin vortex.
  4. 4
    Rakit Pembangkit Frekuensi & Amplifier: Hubungkan output pembangkit sinyal (bisa menggunakan modul function generator XR2206, Arduino DDS, atau aplikasi Tone Generator di ponsel melalui kabel AUX 3.5mm) ke input Amplifier Mono Subwoofer TPA3116D2 (100W) yang ditenagai baterai 12V–24V.Pasang tombol tekan (push button trigger) pada gagang tabung.
  5. 5
    Kalibrasi & Pengujian Bertahap: Setel gelombang pada bentuk Sine Wave (Gelombang Sinus) di angka 30 Hz hingga 45 Hz. Mulailah dengan mengarahkan moncong tabung ke nyala lilin dari jarak 30 cm. Rasakan hembusan pulsa udara di depan lubang moncong, lalu naikkan volume amplifier secara bertahap hingga api langsung padam!

🔬 Mengapa Api Rumah/Gedung Butuh Spesifikasi Khusus?

  • 1. Melawan Kecepatan Apung Api (Buoyant Plume): Api gedung menghasilkan arus konveksi ke atas sebesar 5–12 m/s. Cincin vortex suara harus ditembakkan dengan kecepatan lebih tinggi dari arus tersebut agar sanggup memutus pasokan oksigen.
  • 2. Masalah Bara Kayu & Re-Ignition (Penyalaan Ulang): Sesuai temuan Physics World & George Mason University, gelombang suara mematikan nyala api (flame knockdown) namun tidak mendinginkan bara kayu dalam. Jika suhu kayu masih >400°C, api bisa menyala lagi saat suara berhenti.
  • 3. Solusi Rekayasa Hibrida & Swarm Drone: Untuk kebakaran gedung, meriam vortex akustik digunakan untuk mematikan kobaran api besar dalam hitungan detik, lalu dikombinasikan dengan kabut air mikro (water mist) atau gas N₂ untuk mendinginkan bara dengan penggunaan air 90% lebih hemat dibanding selang pemadam biasa!
